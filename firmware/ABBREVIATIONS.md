# Abbreviations

The coding standard allows abbreviations only from a version controlled
table. This is that table. Add to it before using a new one in code.

Second, minute, hour, day, week, month and year are never abbreviated.
A seconds field is `timeout_seconds`, not `timeout_s` or `timeout_sec`.
